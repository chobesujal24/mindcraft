Minecraft agents that plan, work, and report back.

Mindcraft is a self-hosted agent fleet for Minecraft. It plans its own work, mines and builds through the night, and reports to a production console where every control is wired to a real endpoint.

Explore the production console

Fleet telemetry

Health, hunger, coordinates, ping and current activity for every agent, sampled from the running process.

Work that persists

Grind jobs and Sponge schematic builds survive restarts, with pause, resume, cancel and a material ledger.

Player radar

Contacts within 16, 32 or 64 metres, with bearing, distance, held item and sneak state — when the add-on is armed.

Provider failover

A priority chain of up to 20 OpenAI-compatible routes. On 429, 500 or timeout, the next enabled route takes over.

Service control

Start, restart and stop the real systemd units. Destructive actions ask for confirmation; nothing is simulated.

Terminal dock

Filter unit logs, keep command history, and dispatch server commands to ENI1 without leaving the console.

Self-hosted

Yours, end to end.

One Linux host runs the agent, the supervisor and the console. Nothing leaves your infrastructure unless you send it to a model provider.

  • Node 20+, Mineflayer, and an OpenAI-compatible provider
  • Loopback by default; TLS and a password gate at the public edge
  • systemd units, cron supervision, and a Tailscale path for operators
  • MIT licensed, no analytics, no hosted control plane
