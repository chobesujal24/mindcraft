Under the hood

Quiet on the outside. Busy underneath.

An agent loop, a persistent worker queue and a dependency-free supervisor that keeps the whole thing honest — even when the model is wrong.

An agent that closes the loop

Perceive the world, choose an action, verify the result. A stuck action is cancelled cleanly instead of piling on top of the next one.

Why it exists
Built to be watched, not babysat.

Most bots are a script with a chat window. ENI-01 is a small system: a durable queue, a supervisor with a real API, and a model that can be wrong without taking the host down. The garden is the demo.
